| Command | Description |
| --- | --- |
| WSL commands |     |
| wsl --install | Installs Windows Subsystem for Linux along with the default Ubuntu distribution. |
| wsl --update | Checks for and installs updates for the WSL kernel. |
| wsl --shutdown | Immediately terminates all running WSL distributions and virtual machines. |
| File navigation commands |     |
| ls  | List files and folders     |
| cd  | Change directory    |
| /   | The root directory    |
| ~   | The use home directory    |
| installing programs |     |
| sudo | Super doer to execute programs with higher privileges    |
| sudo apt-get update && sudo apt-get upgrade -y | Running update and upgrade for apt-get    |
| sudo apt-get install &lt;package name&gt; | Install a package or program    |
| sudo apt-get install nautilus | Install the file browser for ubuntu "nautilus"    |
| sudo apt-get install synaptic | Install a GUI package manager "synaptic"  |
